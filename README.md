# แผนสอนวันนี้ (kru_plan)

แอพ Flutter สำหรับครู เปิดตอนเช้าแล้วรู้ทันทีว่า **วันนี้สอนคาบไหน ห้องไหน เรื่องอะไร และแต่ละห้องสอนถึงไหนแล้ว**
ทำงานออฟไลน์ทั้งหมด ข้อมูลเก็บในเครื่อง (shared_preferences + โฟลเดอร์ไฟล์ของแอพ)

## หน้าจอ

| แท็บ | ใช้ทำอะไร |
|---|---|
| **วันนี้** | การ์ดเรียงตามคาบ: เวลา, ชั้น/ห้อง, ห้องที่สอน, เรื่องที่ต้องสอนต่อ, คาบที่เท่าไรจากแผน (เตือนเมื่อเกินแผน), โน้ต "คาบก่อนถึงไหน" + การบ้านที่ต้องตรวจ, แถบความคืบหน้าทั้งวิชา. ด้านบนสรุป "ตอนนี้/ถัดไปคาบไหน อีกกี่นาที". ปัดซ้าย-ขวาดูวันอื่นได้ (เช็กของพรุ่งนี้ตอนเย็น). ตั้งวันหยุดได้จากเมนู ⋮ |
| **ความคืบหน้า** | ทุกห้องแยกตามวิชา: ตอนนี้อยู่เรื่องไหน, %, ห้องไหนช้ากว่าห้องที่นำกี่เรื่อง. แตะห้องเพื่อดูเช็กลิสต์หัวข้อและประวัติการสอน (กดค้างที่หัวข้อ = ตั้งว่าสอนถึงเรื่องนี้แล้ว ใช้ตอนเริ่มใช้กลางเทอม) |
| **ตั้งค่า** | วิชาและหัวข้อ (วางสารบัญทีละบรรทัด, `\| 3` = 3 คาบ, ลากเรียงลำดับได้), ห้องเรียน (สี/ห้อง/วิชา), ตารางสอนแบบตาราง จ.–ศ. แตะช่องเลือกห้อง, เวลาแต่ละคาบ, วันหยุด, สำรอง/กู้คืนข้อมูลผ่านคลิปบอร์ด |

## ไฟล์ สื่อ และรูป
- **สื่อการสอนต่อหัวข้อ** (ตั้งค่า → วิชา → แตะหัวข้อ): แนบ PDF, สไลด์, ใบงาน, วิดีโอ, เสียง, รูป หรือลิงก์ (YouTube, Google Slides, Canva) พร้อมช่อง "แนวการสอน/สิ่งที่ต้องเตรียม" — ขึ้นบนการ์ดหน้า "วันนี้" แตะเปิดได้ทันที
- **รูป/ไฟล์ในบันทึกหลังสอน**: ถ่ายรูปกระดาน ใบงาน ผลงานนักเรียนแนบกับคาบนั้น คาบถัดไปของห้องเดียวกันจะเห็นรูปจากคาบก่อน และดูย้อนหลังได้ในประวัติของห้อง
- แตะเพื่อเปิด (รูปเปิดเต็มจอ ซูม/ปัดดูรูปถัดไปได้) · กดค้างเพื่อลบ
- บนมือถือไฟล์ถูกคัดลอกเก็บในโฟลเดอร์ของแอพ (ไม่หายแม้ลบไฟล์ต้นฉบับ) · บนเว็บจำกัดไฟล์ละ 3 MB
- หมายเหตุ: "สำรองข้อมูล (คัดลอก)" ยังสำรองเฉพาะข้อความและลิงก์ ไม่รวมตัวไฟล์

## การบันทึกหลังสอน (1 แตะ)
- **จบเรื่องนี้** → ห้องนั้นขยับไปเรื่องถัดไปอัตโนมัติ (มีปุ่มเลิกทำ)
- **ยังไม่จบ** → จดว่าถึงตรงไหน + การบ้าน; คาบหน้าของห้องนั้นจะขึ้นโน้ตนี้ให้เห็น
- **งดสอน** → ไม่นับคาบ ไม่ขยับความคืบหน้า

## โครงข้อมูล (`lib/models.dart`)
- `Subject` → `Topic[]` (ชื่อเรื่อง, จำนวนคาบตามแผน) เรียงตามลำดับหลักสูตร
- `ClassGroup` ชั้น/ห้อง + ห้องที่สอน + วิชา + `doneTopicIds` (ความคืบหน้าของห้องนั้น)
- `PeriodTime` เวลาเริ่ม/จบของแต่ละคาบ, `Slot` = วัน × คาบ → ห้อง
- `LessonLog` บันทึกต่อคาบ: วันที่, หัวข้อ, สถานะ (จบ/ยังไม่จบ/งด), โน้ต, การบ้าน, ไฟล์แนบ
- `Attachment` รูป/ไฟล์/ลิงก์ ใช้ทั้งใน `Topic.media` และ `LessonLog.attachments` (`lib/attachments.dart` จัดการเลือก เก็บ เปิด ลบ)
- "สอนต่อเรื่องไหน" = หัวข้อแรกที่ยังไม่อยู่ใน `doneTopicIds`

## รัน
```bash
flutter pub get
flutter run            # มือถือ/อีมูเลเตอร์
flutter run -d chrome  # ทดลองบนเว็บ
```
เปิดครั้งแรกจะมีข้อมูลตัวอย่าง (คณิต ม.2 สองห้อง, วิทย์ ม.1) ลบ/แก้ได้ในแท็บตั้งค่า

## ขั้นต่อไปที่วางไว้
1. แจ้งเตือนตอนเช้า (เช่น 07:00) สรุปคาบวันนี้ + เตือนก่อนเข้าคาบ 5 นาที (`flutter_local_notifications`)
2. วิดเจ็ตหน้าจอโฮม Android/iOS แสดงคาบถัดไป (`home_widget`)
3. ตารางสลับสัปดาห์ A/B และการสอนชดเชย
4. ซิงก์ข้ามเครื่อง / สำรองขึ้น Google Drive (รวมไฟล์แนบ)
